# docs/design/web/ — Design-Dateien für die Handy-Weboberfläche

Gestalterische Vorlagen für die Weboberfläche am Smartphone: Mockups, Farb-/
Layout-Entwürfe, Screenshots zum Abstimmen. Fester Pfad laut Platzierungsregel in
[`../../ARBEITSWEISE.md`](../../ARBEITSWEISE.md) §2.

## Was hierher gehört
- Mockups/Entwürfe der Bedienoberfläche (PNG, Skizze).
- Farb- und Layout-Ideen, Beispiel-Screenshots.

## Was NICHT hierher gehört
- **Der tatsächliche Code** der Weboberfläche — der liegt in
  [`../../../web/`](../../../web/).

## Namenskonvention
`<seite>.png`, z. B. `startseite.png`, `ir-steuerung.png`.
